## 최종 아이디어
- 서비스명: Welfare Next
- 한 문장 소개: 복지정책에서 탈락한 사람에게 탈락 사유를 쉽게 설명하고, 현재 조건에서 받을 수 있는 다음 지원정책과 행동까지 연결하는 AI 복지 네비게이터.
- 해결하려는 문제: 복지정책 탈락자는 행정용어와 복잡한 자격조건 때문에 탈락 이유를 이해하기 어렵고, 이후 가능한 다른 지원제도를 직접 다시 찾아야 한다.
- 주요 사용자: 복지정책을 신청했지만 자격조건 등의 이유로 탈락한 사용자
- 주요 사용자 행동: 탈락 사유와 자신의 조건을 입력하고, 설명·대체 정책·다음 행동을 확인한다.
- 차별화 포인트: 정책 검색에서 끝나지 않고 '탈락 원인 → 대안 정책 → 다음 행동'을 하나의 경로로 연결한다.
- AI 사용 목적: 탈락 사유를 쉬운 말로 재구성하고 사용자 조건과 정책 자격조건을 비교하여 개인별 다음 선택지를 정리한다.
- AI 기술: Microsoft Copilot SDK 필수
- P0 #1: 탈락 사유 쉬운 말 설명
- P0 #2: 사용자 조건 기반 대체 복지정책 추천 및 자격조건 비교
- P0 #3: 재신청·추가서류·이의신청 등 다음 행동 안내
- P1: 여러 정책을 연속해서 연결하는 복지 경로 시각화
- 제외: 로그인, 결제, 알림, 관리자 페이지, 자체 추천모델 학습
