# Screen Spec — Welfare Next

## SCR-01 분석 시작
### 핵심 CTA
- 탈락 결과 분석하기

### 콘텐츠
- Hero: '탈락했다고 끝이 아니에요. 다음 복지를 함께 찾아볼게요.'
- 신청했던 정책명
- 탈락 사유 입력
- 사용자 조건 입력: 연령, 가구형태, 소득 관련 값, 거주지역 등 API 계약에서 확정된 필드

### UI 상태
- Default: 폼 입력 가능
- Validation Error: 필드별 오류
- Loading: 버튼 비활성 + '조건을 확인하고 있어요'
- API Error: 입력 유지 + 재시도

## SCR-02 분석 결과
### 콘텐츠 우선순위
1. 왜 탈락했나요?
2. 지금 검토해볼 지원
3. 자격조건 비교
4. 다음에 무엇을 하면 되나요?

### 상태
- Success: 설명 + 후보 정책 + 다음 행동
- Empty: 추천 후보 없음 + 조건 수정 CTA
- Partial: 미확인 조건을 '확인 필요'로 표시
- Error: 해당 영역 단위 재시도
