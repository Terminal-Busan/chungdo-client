# 아이디어 선정 — Welfare Next

## 해결할 사용자 문제
복지정책에서 탈락한 사용자가 어려운 탈락 사유를 이해하지 못하고, 이후 가능한 지원정책과 필요한 행동을 다시 직접 찾아야 하는 문제를 해결한다.

## 최종 선택과 근거
**Welfare Next**를 최종 아이디어로 고정한다.

- 사용자 문제와 입력·출력이 명확하다.
- AI가 단순 검색이 아니라 행정 문구 설명, 사용자 조건과 정책 조건 비교, 다음 행동 정리에 사용된다.
- 30초~1분 데모에서 가치가 바로 드러난다.
- 로그인이나 복잡한 운영 기능 없이 핵심 체험 구현이 가능하다.

## 한 문장 가치 제안
복지정책에서 탈락한 사람을 방치하지 않고, 탈락 사유부터 다음 지원정책과 행동까지 이어주는 AI 복지 네비게이터.

## 30초 서비스 시연 흐름
1. '주거지원 신청에서 소득기준 때문에 탈락' 입력
2. 사용자 조건 입력
3. AI가 탈락 원인을 쉬운 말로 설명
4. 조건상 검토 가능한 대체 정책 제시
5. 자격조건 비교와 다음 행동 표시

## P0 기능 3개
1. 탈락 사유 쉬운 말 설명
2. 사용자 조건 기반 대체 복지정책 추천 및 조건 비교
3. 다음 행동 안내

## 제외 기능
로그인/결제/알림/관리자 페이지/자체 추천모델 학습.

## 주요 위험 및 대안
- 복지 데이터/API 미확정 → 검증 가능한 최소 데이터셋 사용, Mock이면 명확히 표시
- AI가 자격을 과도하게 확정 → '검토 가능', '확인 필요' 상태 사용
- 개발 시간 부족 → 결과를 한 화면에 통합하고 P1 경로 시각화는 제외
